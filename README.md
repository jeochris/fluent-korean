# 오늘의 한국어 슬랙 봇

매일 슬랙 채널에 사자성어 / 속담 / 관용구를 **뜻과 예문까지** 붙여서 올린다.

## 데이터

`data/daily_ko.json`

| 키 | 개수 | 뜻 | 예문 | 출처 |
|---|---|---|---|---|
| `sajaseongeo` | 608 | ✅ | 33% | 한국어기초사전 + 위키낱말사전 + 나무위키 |
| `sokdam` | 656 | ✅ | 32% | 한국어기초사전 |
| `gwanyonggu` | 2,227 | ✅ | 81% | 한국어기초사전 |

한국어기초사전에는 사자성어가 178개뿐이라 각주구검·결초보은 같은 대표적인 것들이
빠져 있다. 세 곳에서 보충했다.

1. 위키낱말사전 `분류:한국어 한자성어` (`scripts/fetch_wiktionary.py`)
2. 나무위키 `분류:사자성어` 의 **이름 목록**으로 후보를 만들고, 그중 한국어기초사전에
   실려 있는 것의 뜻을 가져옴 (`scripts/fetch_namu_names.py`)
3. 어느 사전에도 없는 나머지는 나무위키 본문에서 가져옴 (`scripts/fetch_namu_defs.py`)

3번만 CC BY-NC-SA 라 별도 파일(`data/namu_sajaseongeo.json`)로 두고 항목마다
`source` 를 남긴다.

나무위키 본문 파싱은 손이 많이 갔다. 요청마다 바뀌는 광고가 섞이고(마침표로 끝나는
문장만 취해서 걸러냄), 분류가 여럿이면 "분류 동음이의어 사자성어"가 되고, 절 제목이
개요가 아니라 뜻인 문서가 있다. 한자와 훈음이 뜻 앞에 붙는 경우는 표제어의 마지막
음절을 표지로 잘라냈다("태평세월"이면 훈음이 "…세월 세 세월 월"로 끝난다).

각 항목: `word`, `mean`, 그리고 선택적으로 `hanja`, `example`, `pos`, `category`, `level`.

### 데이터 재생성

```bash
curl -L -A "Mozilla/5.0" -H "Referer: https://krdict.korean.go.kr/download/downloadPopup" \
  "https://krdict.korean.go.kr/dicBatchDownload?seq=214" -o krdict.zip
unzip krdict.zip -d krdict
python scripts/extract_krdict.py
```

한국어기초사전 전체 덤프는 **로그인 없이** 받을 수 있다(84MB zip → 969MB json, 11개 파일).
`seq=212` 엑셀 / `213` XML / `214` JSON.

## 설치

1. **슬랙 Incoming Webhook 만들기**
   - https://api.slack.com/apps → Create New App → From scratch
   - Incoming Webhooks → 활성화 → Add New Webhook to Workspace → 채널 선택
   - `https://hooks.slack.com/services/...` URL 복사

2. **GitHub 레포에 secret 등록**
   - Settings → Secrets and variables → Actions → New repository secret
   - 이름 `SLACK_WEBHOOK_URL`, 값은 위 URL

3. push 하면 끝. 매일 10:15 KST 에 올라간다.

cron 을 정각(`0 0 * * *`)으로 두면 안 된다. 전 세계에서 몰리는 시간이라 크게 밀리거나
아예 건너뛴다. 실제로 그렇게 두었다가 첫 스케줄이 오지 않았다.

## 로컬 테스트

## 동작 방식

매일 10:15 KST 에 **한 개의 메시지**로 4개 항목을 올린다.

|---|---|---|---|---|
| 1 | 🀄 사자성어 | 1 | 361 / 608 | 361일 |
| 2 | 🗣️ 속담 | 1 | 305 / 656 | 305일 |
| 3 | 💬 관용구 | 2 | 813 / 2,227 | 406일 |

## 걸러내기

두 가지 이유로 항목을 뺀다. 데이터에서 지우지 않고 `easy` / `blocked` 표시만 남기므로,
기준을 바꾸려면 `data/easy_*.json` 이나 `data/blocked.json` 을 고쳐 `normalize.py` 를
다시 돌리면 된다.

### 부적절 (`data/blocked.json`, 102개)

직장 동료가 함께 보는 채널에 봇이 사람 확인 없이 올린다는 점을 기준으로, 욕설·비하·성적
표현을 뺐다. 사전에 실린 표현이라도 그대로 올리기 곤란한 것이 있다.

**표제어가 아니라 뜻풀이가 문제인 경우가 대부분이라, 뜻풀이까지 읽고 판정했다.**
키워드로는 못 잡는다 — `백년가약`이 "년" 때문에 걸리고(오탐), `호박꽃도 꽃이냐`는
표제어에 문제 단어가 하나도 없다(미탐).

| 표제어 | 뜻풀이 |
|---|---|
| 고래(를) 잡다 | 남자의 성기 끝을 덮고 있는 살가죽을 제거하는 수술을 하다 |
| 솥뚜껑 운전수 | (속된 말로) 가정주부 |
| 평생을 맡기다 | 1. 여자가 결혼을 하다 2. 여자를 결혼시키다 |
| 호박꽃도 꽃이냐 | 예쁘지 않은 여자는 여자로 볼 수 없음 |

소재가 무겁다는 이유만으로는 빼지 않았다. `세상을 버리다`(죽다), `콩밥 신세를 지다`,
`뱃가죽이 등에 붙다`(가난) 같은 것은 누구를 깎아내리지 않아 남겼다.

### 뜻풀이 불량 (`data/broken.json`)

나무위키에서 자동 수집한 것 중 뜻풀이가 깨진 것은 표시가 아니라 아예 지운다.
문장이 중간에 끊기거나, 뜻 대신 인용문만 있는 경우다. 책인즉명은 뜻풀이 자리에
성경 구절이 들어와 있었다.

### 난이도

누구나 아는 항목은 올려도 배울 게 없어서 봇이 건너뛴다. 데이터에서 지우지 않고
`easy` 표시만 남기므로, 기준을 바꾸려면 `data/easy_*.json` 목록을 고쳐
`normalize.py` 를 다시 돌리면 된다.

- **사자성어** — 위키백과 본문 등장 횟수(`scripts/wiki_freq.py`)를 통용도 대리 지표로 삼았다.
  31회 이상은 자동, 8~30회 구간은 눈으로 골랐다. 빈도는 "일상에서 얼마나 쓰나"가 아니라
  "백과사전에 얼마나 나오나"라서 아래 구간에서는 어긋난다. 격물치지(17회)가 성리학 문서
  때문에 높게 잡히는 식이다. 그런 것은 남겼다.
- **속담·관용구** — 자동 신호가 없어 직접 판정했다. 위키백과 빈도는 백과사전 문체라
  쉬운 속담도 1~5회밖에 안 나와 쓸 수 없다.
- **관용구 2,227개는 전부 검토**했다. 1,362개가 쉬움으로 표시되어 865개가 남았다.

판정 원칙 하나: **사전 표제어와 실제로 쓰는 형태가 다르면 남긴다.** `불똥이 떨어지다`(실사용은
"불똥이 튀다"), `숨이 턱에 닿다`("숨이 턱까지 차다"), `망을 서다`("망을 보다") 같은 것들이다.
이런 것을 쉽다고 빼면 아무도 안 쓰는 표제형만 남는다.

- 항목은 **섞어둔 순열을 순서대로** 꺼낸다. `EPOCH`(2026-09-07)부터 며칠 지났는지로 위치를 계산하므로
  상태 저장이 필요 없고, 같은 날 여러 번 실행해도 결과가 같다.
  목록을 한 바퀴 다 쓰면 다시 섞어서(회차 +1) 처음부터 돈다.
- 그래서 n개짜리 목록은 **정확히 n일 동안 중복이 없다**. 사자성어 345일, 속담 656일, 관용구 2,227일.
  (매일 새로 무작위로 뽑으면 생일 문제 때문에 178개로도 20일이면 중복이 난다.)
- `EPOCH` 를 바꾸면 전체 순서가 어긋나므로 건드리지 않는다.
- 뜻 아래에 예문이 있으면 인용 블록으로 붙는다. 예문은 항목에 따라 없을 수도 있다.
- 구성을 바꾸려면 `bot.py` 의 `DAILY` 리스트를 수정하면 된다.

## 라이선스

- 국립국어원 한국어기초사전: **CC BY-SA 2.0 KR**
- 위키낱말사전: **CC BY-SA 4.0**

- 나무위키: **CC BY-NC-SA 2.0 KR** (비상업적 이용만 가능)

출처 표시는 이 문서와 데이터의 `source` 필드로 한다. 슬랙 메시지에는 넣지 않는다.
사내 채널에 매일 올라가는 메시지라 줄이 길어지는 것이 실익보다 크다고 보았다.
외부에 공개하는 형태로 쓸 때는 표시를 되살리는 것이 맞다.

## 데이터 만드는 순서

```bash
python scripts/extract_krdict.py      # 한국어기초사전 덤프에서 추출
python scripts/fetch_wiktionary.py    # 위키낱말사전 사자성어 보충
python scripts/normalize.py           # 병합·정리
```

- 사자성어는 네 글자만 남긴다 (`공상`, `면전` 같은 일반 한자어가 섞여 있다)
- 같은 표제어의 여러 뜻은 한 항목으로 합친다. 사전은 다의어를 뜻마다 따로 담고 있는데,
  그대로 두면 봇이 같은 말을 며칠 간격으로 다시 올리는 것처럼 보인다. 뜻은 최대 3개까지 번호를 붙여 나열한다.
